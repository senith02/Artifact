# results/ — Real Outputs Only

Every file here is produced by a **real run** whose command is recorded (R1, R8). No hand-written or
illustrative numbers. Organised by phase:

```
results/
├── p0/   data_profile.json, eval_protocol.md, carbon provenance
├── p1/   calibration/, shap/, model_report.md  (answers RQ1)
├── p2/   simulator sample runs
├── p3/   strategy_results.*, trade-off figures, sensitivity.*, evaluation_report.md  (RQ2–RQ4)
└── ...
```

If you cannot point a number in the dissertation to a file here (or to the decision log / source of
truth), it is not a result — see `governance/02_ANTI_HALLUCINATION.md`.
